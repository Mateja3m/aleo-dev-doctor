# Contributing

## Setup

1. Install Node.js 18.18+ and npm.
2. Run `npm install`.
3. Run `npm test` and `npm run lint` before opening a PR.

## Development Workflow

- Keep PRs focused and small.
- Add or update tests for behavior changes.
- Use `npm run format:write` for formatting.

## Commit and PR Guidance

- Use clear commit messages.
- Explain the problem and the solution in PR descriptions.
- Include CLI output snippets when adding new checks.
